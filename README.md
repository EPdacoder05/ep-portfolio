# Ellis Pinaman Portfolio

A zero-build static portfolio designed for Replit, GitHub Pages, Netlify, or any static host.

## Run in Replit

1. Create a new **HTML/CSS/JS** Repl.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Press **Run**.
4. Replace project links or copy as needed.
5. Add your resume PDF to the project and link it from the header once ready.

## Before publishing

- Replace the two AWS certification entries from **In progress** to **Verified** only after the exams are passed.
- Add the Credly badge URLs when available.
- Add a custom domain if desired.
- Consider adding screenshots / architecture diagrams as local images under `/assets`.
- If NullPointVector becomes a consumer app, add a dedicated Privacy page and data-subject request flow before claiming GDPR/CCPA compliance.
